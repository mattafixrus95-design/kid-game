# Сборка APK/AAB для RuStore (TWA)

## Статус

Всё, что можно было подготовить **офлайн, без выхода в реальный интернет**,
сделано и лежит в этом репозитории. Скомпилировать и подписать сам APK/AAB
здесь не вышло — у этой рабочей сессии нет сетевого доступа к `dl.google.com`
(Android SDK/Gradle) и даже к самому `kid-game-two.vercel.app` (заблокировано
политикой окружения). Реальную сборку нужно доделать в среде с обычным
интернетом — ниже точные шаги, чтобы это заняло 10-15 минут.

## Что уже готово

- `android/twa-manifest.json` — полный конфиг для Bubblewrap: package id,
  название, цвета, версия, ссылка на манифест сайта
- `public/.well-known/assetlinks.json` — уже задеплоится вместе с сайтом,
  содержит правильный package name и SHA-256 отпечаток релизного сертификата
- `vercel.json` — форсирует `Content-Type: application/json` для
  `assetlinks.json` (иначе некоторые статические хостинги отдают dotfiles
  с неверным типом, и Google не сможет проверить Digital Asset Links)
- Релизный keystore + пароли — переданы тебе отдельным файлом
  (`android.keystore`, `keystore-credentials.txt`) через SendUserFile,
  **в git не коммитятся** (см. `.gitignore`)

## Что нужно сделать (в среде с интернетом)

1. Установить Bubblewrap:
   ```bash
   npm install -g @bubblewrap/cli
   ```

2. Положить присланный `android.keystore` в папку `android/` этого репозитория
   (рядом с `twa-manifest.json` — путь в конфиге `"path": "./android.keystore"`
   это ожидает).

3. Собрать APK/AAB:
   ```bash
   cd android
   bubblewrap build
   ```
   Bubblewrap спросит пароль keystore и пароль ключа — оба значения одинаковые,
   смотри `KEYSTORE_PASSWORD` в `keystore-credentials.txt`.

   При первом запуске Bubblewrap автоматически скачает JDK и Android SDK
   (если их ещё нет) — на это нужен обычный, не ограниченный интернет.

4. На выходе получится:
   - `android/app-release-signed.apk` — для ручной установки на телефон
   - `android/app-release-bundle.aab` — для загрузки в RuStore

5. Проверить, что `assetlinks.json` реально видно на проде (обязательно
   **после** деплоя ветки с этими изменениями):
   ```
   https://kid-game-two.vercel.app/.well-known/assetlinks.json
   ```
   Должен открыться JSON, а не 404.

## Permissions — что должно быть в AndroidManifest.xml

Bubblewrap по умолчанию добавляет в шаблон TWA только:
- `android.permission.INTERNET`
- `android.permission.ACCESS_NETWORK_STATE`

Больше ничего добавлять не нужно (камера, микрофон, геолокация, контакты,
файлы, уведомления, рекламные ID — намеренно исключены по ТЗ). После сборки
стоит один раз открыть `android/app/src/main/AndroidManifest.xml` и убедиться,
что там ровно эти два permission и ничего лишнего.

## versionName / versionCode

Уже прописаны в `twa-manifest.json`:
- `appVersionName: "1.0.0"`
- `appVersionCode: 100`

Синхронизировано с `src/version.js` (`APP_VERSION = "1.0.0"`) — по договорённости
эти два номера дальше двигаются вместе только на релизах APK, а не на каждый
коммит в master (иначе пришлось бы перезаливать APK в RuStore слишком часто).

## Чек-лист проверки на телефоне после установки APK

- [ ] приложение устанавливается и открывается
- [ ] название `Развивашки 2–5 лет`, иконка — наше лого
- [ ] нет верхней строки браузера (адресной строки) — если она есть, значит
      `assetlinks.json` не подтянулся или не совпадает с fingerprint — проверить
      shell: `keytool -list -v -keystore android.keystore -alias razvivashki`
      и сверить SHA-256 с тем, что в `assetlinks.json`
- [ ] Skills → Mechanics → Content → Subsets → Game — переходы работают
- [ ] все 5 навыков открываются, по механике из каждого раздела запускается
- [ ] кнопка "назад" (аппаратная/жест) работает адекватно
- [ ] на игровых экранах нет нижнего сервисного блока (ServiceBar) — только
      BottomBar с "Назад"/игровыми кнопками
- [ ] форма обратной связи (EmailJS) отправляется
- [ ] "Поддержать" открывает CloudTips во внешнем браузере/вкладке
- [ ] политика конфиденциальности открывается и читается
- [ ] с интернетом — события Яндекс Метрики уходят (см. Network в
      chrome://inspect при подключении телефона по USB)
- [ ] без интернета — приложение не падает, экраны открываются из кэша
- [ ] кнопки "Проверить обновление" нигде нет
- [ ] версия в "О приложении" отображается как `1.0.0`

## Известные ограничения на момент подготовки

- Реальный APK/AAB не собран в этой сессии — только полный набор конфигов
  и секретов для сборки одной командой в среде с интернетом
- `assetlinks.json` не проверен вживую на проде (домен был недоступен из
  этой сессии) — обязательно проверить URL из шага 5 после деплоя
- SHA-256 в `assetlinks.json` должен совпадать с тем, что реально зашито
  в `android.keystore` — при генерации нового keystore (если этот потеряется)
  обязательно пересобрать `assetlinks.json` с новым отпечатком
